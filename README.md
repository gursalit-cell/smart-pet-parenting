# Smart Pet Parenting 🐾
**Digital Routine, GPS Tracking & Health Directory for Urban Animal Welfare**

[![Live Demo](https://img.shields.io/badge/View-Live_Demo-teal.svg)](https://gursalit-cell.github.io/smart-pet-parenting/)

## 📌 Project Overview
"Smart Pet Parenting" is a frontend web dashboard designed to tackle the challenges of modern pet care in urban environments like Pune. It centralizes a pet's daily exercise routine, nutrition, GPS tracking logs, and medical records into a single, accessible digital workspace. 

This project was developed as an academic field work and research initiative to study the impact of digital tracking on animal welfare and routine consistency.

## 🚀 Features
* **Pet Profile & Metrics:** Tracks age, weight, and height to determine dynamic care needs.
* **Custom Diet & Nutrition:** Generates large-breed specific feeding guidelines (commercial and homemade recipes).
* **Interactive Care Checklist:** A daily task tracker for walks, training, nutrition, and socialization.
* **Activity Track Record:** A visual 7-day log to ensure exercise targets are met.
* **Local Safe Grounds Directory:** Verified pet-friendly zones and off-leash trails in Pune (e.g., Viman Nagar Dog Park, Vetal Tekdi).
* **Emergency Vet Hub:** Quick-call access to 24/7 rescue NGOs and clinics in Pune.
* **Academic Survey Integration:** Embedded Google Form link to collect real-world data on urban pet parenting challenges.

## 🛠️ Built With
* **HTML5** - Core structure
* **Tailwind CSS (CDN)** - Modern, responsive UI styling
* **Vanilla JavaScript** - Interactive checklist functionality and DOM manipulation
